---

## ✨ المميزات (Features)

- 🎨 **تصميم فاخر (Dark Gold Theme)**: هوية بصرية مدمجة بالأسود والذهبي مع تأثيرات Glassmorphism.
- ⚡ **أنميشن كتابة تفاعلي (Typewriter Animation)**: كتابة واقعية ومستمرة لشعارات الاستوديو في قسم الهيرو.
- ✨ **جزيئات ذهبية حركية (Gold Ambient Particles)**: خلفية تفاعلية تعطي طابعاً سينمائياً فاخراً.
- 🖼️ **معرض أعمال متكامل (Interactive Portfolio & Lightbox)**: تصفية وتكبير الصور بجودة فائقة مع التحكم الكامل.
- 📱 **متجاوب بالكامل (Fully Responsive)**: متوافق 100% مع أجهزة الجوال، الأجهزة اللوحية والشاشات الكبيرة.
- 💬 **حجز مباشر عبر واتساب (Instant WhatsApp Booking)**: نموذج حجز ينشئ رسالة منسقة تلقائياً ومباشرة للواتساب.
- 🚀 **أداء وسرعة عالية (Vanilla Web Stack)**: مبني بتقنيات الويب النقية (HTML5 / CSS3 / JavaScript) بدون أي مكتبات ثقيلة خارجية.

---

## 🛠️ التقنيات المستخدمة (Tech Stack)

- **HTML5**: هيكل دلالي يدعم اللغة العربية ونظام RTL بالكامل.
- **CSS3 (Vanilla CSS)**: نظام تصميم متكامل مع Design Tokens، تدرجات ذهبية ومؤثرات حركية فائقة النعومة.
- **JavaScript (Vanilla ES6+)**: إدارة معرض الصور، السلايدر، المحاكاة التفاعلية، ونموذج الحجز.
- **Google Fonts**: خط `Alexandria` للعناوين البارزة وخط `Tajawal` للمحتوى والنصوص.
